# Wanjiru Ngulukyo & Company Advocates

Static multi-page website built by adapting the Cecilia Mwaura & Co. Advocates design structure requested by the client.

## Included
- Home, About, Practice Areas, Leah Wanjiru profile, Insights and Contact pages
- Privacy, Terms and 404 pages
- Mobile-responsive sticky navigation
- Mobile-safe animated WebP logo plus original 4K MP4 source
- Fixed WhatsApp/call contact rail
- Google Maps embed for Keore House / Joska Town
- SEO metadata, Open Graph image, structured data, sitemap and robots.txt

Run `npm run check`, then `npm run build`.
